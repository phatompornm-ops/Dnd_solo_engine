# 🎲 Solo DnD → Multiplayer Tabletop RPG

เกม D&D 5e แบบมี AI เป็น Dungeon Master (Gemini) เล่นได้ทั้งคนเดียวและออนไลน์กับเพื่อน **2–6 คน**
เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้องมี Backend ใช้ [Supabase Realtime](https://supabase.com/docs/guides/realtime) (Broadcast + Presence) เชื่อมผู้เล่น จึงไม่ติดปัญหา NAT/Firewall

## ✨ ฟีเจอร์

- AI Dungeon Master ใช้ Gemini API ตามกฎ D&D 5e
- ระบบทอยเต๋า ค่าสถานะ คลาส สล็อตเวท เสบียง เวลา และสภาวะต่างๆ
- ระบบเสียงและเพลงพื้นหลังตามฉาก
- Combat Tracker เรียงลำดับ Initiative และกดสั่งการได้เฉพาะเจ้าของเทิร์น
- **มัลติเพลเยอร์**
  - สร้างห้อง / เข้าห้องด้วยรหัส 6 ตัวอักษร (สูงสุด 6 คน)
  - Sync แชต การทอยเต๋า เพลง/เสียง ฉาก และสมุดบันทึก (Journal) แบบ Realtime
  - Party Roster HUD แสดงชื่อ คลาส แถบเลือด AC และสภาวะของทุกคน
  - แจ้งเตือนเมื่อมีคนเข้า/ออกห้อง
  - Host เตะผู้เล่นได้ และทุกคนมีปุ่มออกจากห้อง

## 🧰 สิ่งที่ต้องมี

| ใคร | ต้องมี |
|---|---|
| Host (คนเดียว) | Gemini API Key + Supabase URL/Anon Key |
| เพื่อน | Supabase URL/Anon Key (ชุดเดียวกับ Host) เท่านั้น |

ทุกอย่างฟรี (Free Tier)

## 🚀 ตั้งค่า (ทำครั้งเดียว)

### 1) สร้างโปรเจกต์ Supabase
1. สมัครที่ [supabase.com](https://supabase.com) แล้วสร้างโปรเจกต์ใหม่
2. ไปที่ **Project Settings → API Keys** คัดลอกคีย์ **anon public** (ขึ้นต้น `eyJ...`) จากแท็บ *Legacy API keys*
   (ถ้าใช้ `sb_publishable_...` ได้ก็ใช้ได้ แต่ถ้าต่อไม่ติดให้ใช้ anon แบบ `eyJ...`)
3. ไปที่ **Data API** คัดลอก **Project URL** (รูปแบบ `https://xxxx.supabase.co`)
4. ไม่ต้องสร้างตารางหรือรัน SQL

> ⚠️ ห้ามใช้ `secret` หรือ `service_role` key ในไฟล์ HTML เด็ดขาด ใช้ได้เฉพาะ anon/publishable key

### 2) ขอ Gemini API Key (เฉพาะ Host)
สร้างที่ [Google AI Studio](https://aistudio.google.com/apikey)

### 3) (ทางเลือก) ตั้งค่าเริ่มต้นในโค้ด
ค้นหา `SB_DEFAULT` ใน `index.html` แล้วใส่ค่าเพื่อไม่ต้องกรอกทุกครั้ง

```js
const SB_DEFAULT = { url: "https://xxxx.supabase.co", key: "eyJ..." };
```

ถ้าไม่ตั้ง ผู้เล่นกรอกในเกมได้ ระบบจะจำไว้ในเบราว์เซอร์

## 🌐 เผยแพร่บน GitHub Pages

1. อัปโหลด `index.html` ขึ้น repository
2. **Settings → Pages → Branch: main / root → Save**
3. ส่งลิงก์ `https://<username>.github.io/<repo>/` ให้เพื่อน

## 🎮 วิธีเล่นออนไลน์

### Host
1. เปิดเกม สร้างตัวละคร และใส่ Gemini API Key ในหน้า ⚙️ ตั้งค่า
2. กด **👥 ห้อง** → กรอก Supabase URL และ Anon Key
3. กด **สร้างห้อง** จะได้รหัสห้อง ส่งให้เพื่อน
4. **เปิดหน้าเว็บค้างไว้ตลอดการเล่น** เพราะ Host เป็นคนเรียก Gemini และตัดสินผลทั้งหมด

### เพื่อน
1. เปิดลิงก์เกม สร้างตัวละครของตัวเอง
2. กด **👥 ห้อง** → กรอก Supabase URL และ Anon Key ชุดเดียวกับ Host
3. ใส่รหัสห้อง แล้วกด **เข้าห้อง**
4. พิมพ์การกระทำในช่องแชต DM จะตอบให้ทั้งปาร์ตี้เห็น

### ระหว่างเล่น
- **ทอยเต๋า:** ทอยได้เมื่อ DM สั่งที่ชื่อตัวละครของคุณเท่านั้น (ทอยครั้งเดียวต่อคำสั่ง)
- **Combat:** ลำดับเทิร์นเรียงตาม Initiative ปุ่มโจมตี/จบเทิร์นกดได้เฉพาะเมื่อถึงเทิร์นของคุณ
- **HP:** DM ปรับ HP ตามชื่อตัวละคร ดูแถบเลือดทุกคนได้ที่ Roster HUD
- **เตะผู้เล่น (Host):** กด 👢 บนการ์ดผู้เล่น คนที่ถูกเตะจะเข้าซ้ำในแท็บเดิมไม่ได้จนกว่าจะปิดห้อง
- **ออกจากห้อง:** กด 🚪 หน้านี้จะรีโหลดและกลับไปใช้เซฟเล่นคนเดียวของตัวเอง
  ถ้า Host ปิดห้อง ผู้เล่นทุกคนจะถูกตัดออก

## 🧠 โครงสร้างการทำงาน

```
เพื่อน ──(Supabase Broadcast)──▶ Host ──▶ Gemini API
   ▲                              │
   └──────(บรอดแคสต์เรื่องเล่า/ฉาก/เสียง/Roster)──┘
```

Host เป็นผู้ตัดสิน (host-authoritative) ผู้เล่นส่งแค่การกระทำและผลทอย Host ตรวจสอบก่อนส่งให้ DM
Presence ใช้ตรวจจับคนเข้า/ออกห้อง

## ❓ แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| เชื่อม Supabase ไม่ได้ | ตรวจ URL/Key ให้ตรงกัน ลองใช้ anon key แบบ `eyJ...` |
| เข้าห้องแล้ว "ไม่พบห้อง" | ตรวจรหัสห้อง และให้ Host เปิดหน้าเว็บค้างไว้ |
| ห้องเต็ม | รองรับสูงสุด 6 คน (Host + 5) |
| DM ไม่ตอบ | Host ต้องใส่ Gemini API Key และมีโควตาเหลือ |
| ไม่มีเสียง | คลิกที่หน้าเว็บหนึ่งครั้ง เบราว์เซอร์ต้องการให้ผู้ใช้โต้ตอบก่อนเล่นเสียง |

## 🔒 หมายเหตุด้านความปลอดภัย

- ผู้ที่มีรหัสห้องและ anon key เข้าห้องได้ ควรแชร์เฉพาะคนที่ไว้ใจ
- Gemini API Key เก็บในเบราว์เซอร์ของ Host เท่านั้น ไม่ถูกส่งให้เพื่อน
- ห้ามอัปโหลด API Key ของตัวเองลง repository สาธารณะ
